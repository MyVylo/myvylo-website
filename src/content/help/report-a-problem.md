Email **[hi@myvylo.com](mailto:hi@myvylo.com?subject=Something%20isn%E2%80%99t%20working%20in%20Vylo)**. You don’t need to know what caused the problem.

Include the screen, what you tried, and what happened. Let us know whether you’re using the web or iPhone app. An error message or screenshot with private details hidden helps too.

For a budget or report, include the month. For a bank issue, include the institution and sync status.

## Should I try again?

For a payment or account-deletion request, check the result before submitting it again. If the status is unclear, tell us—we’ll help confirm what happened.
