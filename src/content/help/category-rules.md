A keyword helps Vylo recognize text in a merchant name or transaction description. Choose something distinctive, such as a particular shop’s name. A broad word can match unrelated purchases.

## What can I edit?

Categories that support custom keywords show **Your custom keywords** and an **Add keyword** field. You can add a word or remove one of your own. Built-in matches may be shown for reference without an edit control.

Custom keywords work alongside automatic matching. They don’t replace every other rule. For one merchant that always belongs in the same category, [Remember merchant](/help/articles/remember-merchant/) is usually simpler.

## Do rule changes fix old transactions?

Rule changes affect future sorting. Review existing transactions separately if you need to correct them.

Where **Restore original rules** is available, it returns the category to its starting rules. Check the confirmation before discarding changes you want to keep.
