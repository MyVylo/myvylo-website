Check the month at the top of the report and select the same month in the dashboard. A completed month’s report won’t match a dashboard showing this month so far.

## What else can change the total?

A late bank import, a category correction, or a duplicate transaction can change the records behind the number. A budget comparison also uses the budget for that month, which may differ from your current plan.

Look at the report’s category breakdown and the transactions behind any unexpected amount. If processing was still running, reopen the report after it finishes.

## The same month still doesn’t match

Email **hi@myvylo.com** with the month and the two totals. Mention any recent bank reconnection or category changes so we can trace the difference.
