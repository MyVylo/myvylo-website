**Two-step sign-in is always on.** When Vylo needs to verify a new device, it sends a one-time code to your account email.

## The code hasn’t arrived

Check the email address, inbox, and spam folder. If you request another code, use the newest message. Enter it in Vylo; don’t send it to support or anyone else.

## What is a trusted device?

Vylo can remember a verified device so it doesn’t need the same email check every time. Clearing trusted devices makes later sign-ins require verification again.

Trust and an active session are different. To end someone’s current access, [sign out that session](/help/articles/signed-in-devices/).

## I can’t access that email anymore

Contact **hi@myvylo.com** from an address you can use and explain what happened. We’ll help you through account recovery.
