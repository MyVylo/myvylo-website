Check the selected month before editing. Changing a planned amount updates the comparison with spending; it doesn’t change the purchases already recorded.

If a category looks over budget because a transaction is wrong, [correct the transaction](/help/articles/change-transaction-category/) instead of raising the budget to hide the difference.

## Does this change other months?

Use the month and scope shown by the editor. Don’t assume an edit to this month changes earlier budgets. Check a future month separately when planning ahead.
