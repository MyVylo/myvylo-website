The household owner can request a data export in **Settings → Privacy & Security**. Once it’s ready, download it before the link expires. Request a fresh export if the earlier download is no longer available.

For a spreadsheet of transactions, [Export CSV](/help/articles/export-transactions/) is the smaller option.

## Exporting before deletion

Download the file you want to keep before deleting your account. Requesting an export doesn’t automatically save it to your device.

The file contains household financial information, so keep it somewhere private.
